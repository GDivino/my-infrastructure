# Agent Guidelines for my-infrastructure

Monorepo containing Terraform and Ansible code for managing AWS and OCI resources. Three independent projects:
- `s3-backend` - Bootstrap Terraform state storage (apply **first**)
- `identity-center` - AWS IAM Identity Center (SSO)
- `homelab` - OCI + Ansible for personal homelab

## Build, Lint, Test Commands

Each directory is an independent project root. Run commands from within the project directory.

### Terraform
```bash
terraform fmt -recursive      # Format code
terraform validate            # Check syntax
terraform init                # Initialize backend and providers
terraform plan                # Preview changes (always run before apply)
terraform apply               # Apply changes
```

### Ansible (homelab only)
```bash
cd homelab
ansible-playbook -i ansible/inventory.ini ansible/site.yml --syntax-check  # Syntax validation
ansible-playbook -i ansible/inventory.ini ansible/site.yml --check --diff   # Dry run
ansible-playbook -i ansible/inventory.ini ansible/site.yml                   # Run playbook
```

**Critical:** The playbook uses `SHELL=/bin/bash ansible-playbook ...` (see `ansible.tf:45`) to prevent jump host issues with zsh.

## Version Requirements

- **Terraform:** `>= 1.13.3` for all projects
- **OCI Provider:** `7.22.0` (homelab)
- **AWS Provider:** `~> 6.16.0` (s3-backend, identity-center)
- **Auth0 Provider:** `>= 1.0.0` (identity-center/auth0/ only)

## Architecture Notes

### Homelab (OCI)
- Public subnet: VPN bastion (WireGuard) + Traefik reverse proxy
- Private subnet: n8n automation server (accessible via VPN or Traefik)
- Ansible inventory generated from `ansible/inventory.tpl`
- Playbook generated from `ansible/site.tpl` with variable substitution

### identity-center (AWS)
- Has an `auth0/` subdirectory with separate Terraform config (`~> 1.5.0`)
- Uses AWS profile `jing` for S3 backend (see `provider.tf:17`)

## Secrets Management

- Never commit `*.tfvars` files (gitignored)
- Use `TF_VAR_<name>` environment variables for sensitive inputs
- Required variables defined in `variables.tf` - check before running `init`

## Key Conventions

1. **Monorepo structure:** Each project directory is self-contained with its own `providers.tf`, `variables.tf`, `outputs.tf`
2. **S3 Backend:** All projects use `profile = "jing"` and bucket `jing-infrastructure-state`
3. **Generated files:** `ansible/inventory.ini` and `ansible/site.yml` are generated by Terraform - don't edit manually
4. **Apply order:** `s3-backend` must exist before other projects can use remote state

## Troubleshooting

- **Traefik auth loop:** Password must be properly hashed with `htpasswd` (see `homelab/README.md:32`)
- **wg-easy 502 error:** Set container `HOST` env var to `0.0.0.0`
- **SSH jump host fails:** Use `SHELL=/bin/bash` prefix for Ansible commands

## Development Workflow

1. Run `terraform validate` and `terraform fmt -recursive` before committing
2. Always run `terraform plan` before `terraform apply`
3. Review plan output carefully - never apply destructive changes without approval
4. For homelab changes affecting Ansible: update `ansible/*.tpl` templates, not generated files
